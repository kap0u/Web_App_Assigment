# Student Discussion Web Application

A Java web application developed for a university Web Technologies course. 
The application allows users to register/login, create topics, post messages, 
and update their password.

## Technologies
- Java
- Servlets
- JSP
- HTML/CSS/JavaScript
- MySQL
- JDBC
- Apache Tomcat

## Features
- User login
- Password update
- Topic creation
- Message posting
- MySQL database integration

## How to run
1. Import the SQL file into MySQL.
2. Place the project folder inside Tomcat webapps.
3. Start Apache Tomcat.
4. Open the application in the browser.
